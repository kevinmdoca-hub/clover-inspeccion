# Event Contract

| Event | Meaning | App responsibility |
|---|---|---|
| `clover-menu` | User wants workspace switcher | Open Clover workspace drawer |
| `clover-home` | User tapped Clover mark | Navigate to Clover/Home |
| `clover-create` | User tapped + | Open workspace-specific create flow |
| `clover-sync` | User tapped Sync | Show sync detail / invoke sync behavior |
| `clover-settings` | User tapped gear | Open shared Settings shell |

The component owns presentation. The app owns behavior.
