Clover Inspection PWA — v0.9.2 DEV

Focused Advisor-shell mobile patch.

Changes:
- Prevents horizontal sheet panning/overflow on iPhone.
- Disables pinch zoom in the installed app and constrains interaction to vertical panning.
- New Inspection sheet fields now change by inspection type.
- Acquisition / Intake uses Bought From / Comprado a instead of Client.
- Other inspection purposes use purpose-specific labels for party, location, date and time.
- Acquisition source is stored separately from Clover client identity so sellers do not appear in Clients.
- Mobile date/time and action layouts stack safely at narrow widths.
- Existing inspection engine, offline persistence, evidence, guided photos and PDF behavior remain unchanged.
